# CLOUD-NOTES: что ломалось в облаке и что помогло

## Проблемы и решения
1. **ffmpeg / compositor без прав на запуск** (`EACCES`, код 126, в GitHub Actions `join` — `ffmpeg: Permission denied`).
   - Решение: `chmod +x` для `ffmpeg`, `ffprobe`, `remotion` в `node_modules/@remotion/compositor-*` сразу после `npm ci` (в `render` и `join`). Локально — то же вручную.
2. **Рендер падал на «delayRender "fonts" … ~118 с»** (вкладка умирала через ~2 минуты, куски в 600 и 150 кадров).
   - Причина: таймер модульного `delayRender('fonts')` в `src/Root.tsx` не снимался и убивал любую вкладку.
   - Решение: таймаут 3 600 000 мс в `Root.tsx` (правка проекта, не скилла). После этого куски по 150 кадров идут без сбоев.
3. **ElevenLabs: 429 и паузы.**
   - Счётчик использования отстаёт, из-за этого лишний переход на второй ключ.
   - Решение: локальный учёт кредитов (`public/vo/.eleven-ledger.json`, без ключей), повтор с ожиданием при 429, пауза 1,2 с между репликами, при 429 на проверке подписки верим локальному счёту, второй ключ только когда не хватает кредитов. Ключи только из `ELEVENLABS_API_KEY` / `ELEVENLABS_API_KEY_2`, в код и git не попадают.
4. **Прокси для Node.** Облако ходит наружу через прокси: `fetch` и WebSocket его по умолчанию игнорируют.
   - Решение: `NODE_USE_ENV_PROXY=1` для `fetch` (инструменты перезапускают себя с ним); `https-proxy-agent` для `msedge-tts`.
5. **Число вкладок и concurrency.** `render.mjs` читает concurrency из секций `long` / `short` файла `src/story/render.json`, а не из корня; на 4 ядрах больше 4 нельзя; у нас 3.
   - В workflow число вкладок берётся из того же файла (по композиции), не больше ядер раннера; при повторе куска — вдвое меньше вкладок.
6. **Лимиты GitHub Actions и артефактов.**
   - Публичный репозиторий: минуты бесплатны без лимита, раннер 4 ядра. Приватный (Free): 2 000 мин в месяц, раннер 2 ядра (рендер примерно вдвое медленнее), 500 МБ на артефакты.
   - Оценка (по замерам, не проверено на GitHub): 155 кусков лонга ≈ 530 МБ, итоговый mp4 ≈ 550 МБ, пик ≈ 1,1 ГБ.
   - Решение: куски живут 1 день, после склейки `join` сам удаляет `chunk-*` через `gh api` (нужен `actions: write`); итоговый файл — 14 дней. Параллельность куски: `max-parallel: 10`, каждый кусок до 30 мин и один повтор.
   - `public/sfx/bed.wav` (≈ 99 МБ) и `bed_short.wav` в git не кладём (`.gitignore`), подложку собирает `join`.
7. **Правка join.**
   - Был демо-bed из репозитория и подложка с кадра 0 для любого диапазона. Теперь `join`: склейка без перекодирования → `check-plans` и `make-sound` (для Short — `short-sound.json`) → вырезка подложки под диапазон → `mix-audio` с голосом диапазона → `loudness` до −16 LUFS → артефакт → удаление кусков. Таймаут `join` — 60 мин.
   - Пустая подложка на 1 с в `render`-job нужна только затем, чтобы немой рендер картинки не искал файл.
8. **Мелочи.** `pgrep`/`pkill` по шаблону убивают собственную оболочку и оставляют сирот Remotion (убивать по PID); `--chunk` у `render.mjs` не знает диапазонов, для частичного рендера есть `render-part.mjs` и `plan-chunks.mjs`.

## Порядок работы над новым роликом
1. **Шаг 0.** Установка скилла в `~/what-if-videos/<имя>`; сразу `chmod +x` для бинарников Remotion и проверка прокси (`NODE_USE_ENV_PROXY=1`); в `Root.tsx` поднять таймер шрифтов; `render.json` с `concurrency` в секциях `long` и `short`.
2. **Сценарий и озвучка.** `script.md` → `lines.json` и `voices.json` → `eleven-voice.mjs --plan` (считаем знаки и кредиты, оба ключа) → озвучка без печати ключей, повтор только упавших реплик → `prep-timeline` (нет строк CHECK).
3. **Сцены партиями** (по 2–3 части): `config.ts`, `cast.ts`, `places.tsx`, `shots*.tsx` → `check-plans` → `storyboard.mjs Long --frames …` каждые 2,5 с, смотреть глазами, править, коммит и пуш после каждой партии.
4. **Звук.** `sound.json` (эмбиент на каждую локацию, эффекты на действия) → `check-plans`, затем `make-sound` → проба `mix-audio` и `loudness --measure`.
5. **Рендер на GitHub Actions.** Репозиторий с правом записи у приложения Claude; Run workflow `render`: `composition = Long`, `range` (сначала кусок `lines:001-025`, потом `lines:001-175`), `chunk = 150`; повтор упавшего куска через «Re-run failed jobs»; итог — артефакт `video-…`; `check-video` (мигания и стыки смотреть кадрами).
6. **Шортс recut.** Выбрать реплики из лонга (без новой озвучки) в `short-pick.json` → `node tools/make-short-timeline.mjs` → `short.ts` (вырезки и вертикальные карточки в `shortV.tsx`) → `short-sound.json` → раскадровка `storyboard.mjs Short --every 2.5` → workflow с `composition = Short`, `range = lines:001-011`.
7. **Превью и сдача.** Промт по `thumbnail.md` → превью → файл и описание.
